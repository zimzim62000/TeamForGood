# Neon Dodger — jeu de démonstration

- Objectif : déplacer le carré orange et collecter le pixel jaune.
- Contrôles : flèches, ZQSD ou WASD.
- Score : 100 points par pixel collecté.
- Durée : 30 secondes, contrôlées par COM Arcade.
- Assets : aucun asset externe.
- Licences : code original du projet COM Arcade.

Ce jeu sert uniquement à valider l'intégration GameKit. Il sera remplacé par un jeu hebdomadaire livré selon `BRIEF_JEU_HEBDO.md`.
